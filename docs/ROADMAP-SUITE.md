# Matharium — المرحلة الثانية: حزمة الحاسبات والقوائم

هذه الخطة تحوّل Matharium إلى **حزمة حاسبات** مستقلة، مستوحاة من حزمة GeoGebra (المراجع: الصور المرفقة وموقع https://www.geogebra.org)، بهوية Matharium الخاصة: الألوان والخطوط من دليل التصميم، **دون نسخ اسم GeoGebra أو شعاره أو أيقوناته**.

تضيف الخطة:
- قوائم النقر الأيمن.
- خيارات عرض جديدة (أنواع الشبكة، والإسقاط ثلاثي الأبعاد).
- نافذة خصائص الكائن.
- ثلاثة تطبيقات جديدة: **الحاسبة العلمية**، و**CAS**، و**حاسبة الاحتمالات**.
- نقل زر اللغة إلى الإعدادات.

**كل خطوة تُخطَّط ثم تُنفَّذ في جلسة Claude Code مستقلة.** الجلسة تبدأ بوضع التخطيط (Plan mode)، وتعرض الخطة عليك للموافقة، ثم تنفّذ على فرع مستقل، وتنتهي بـ Pull Request لا تدمجه بنفسها.

## قواعد مشتركة لكل خطوة

اقرأ هذا القسم قبل أي خطوة.

1. **خطّط أولاً:** ادخل وضع التخطيط، واقرأ الكود المعني، واعرض الخطة للموافقة قبل أي تعديل. الخطة تذكر الملفات التي ستتغير، وما يُعاد استخدامه، وكيف ستتحقق.
2. **ابدأ من `main` محدَّث** وأنشئ فرع الخطوة. اقرأ `README.md` و`docs/ROADMAP.md` (القواعد المشتركة فيه ما زالت سارية: ثنائية اللغة، والعمل دون إنترنت، والاختبارات، وعدم الدمج).
3. **الهوية:** استخدم ألوان وخطوط دليل التصميم (متغيرات CSS في `src/styles/app.css`). المرجع هو **سلوك** GeoGebra ووظائفه، لا مظهره ولا أيقوناته ولا نصوصه حرفياً. لا تذكر اسم GeoGebra داخل التطبيق.
4. **إمكانية الوصول:**
   - كل قائمة تُفتح أيضاً من لوحة المفاتيح (زر Menu أو Shift+F10)، وتُغلق بـ Esc.
   - التنقل بالأسهم، و`role="menu"` و`menuitem` و`menuitemcheckbox`.
   - على اللمس: الضغط المطوّل (≈ 500ms) يفتح نفس القائمة.
5. **التوافق مع الملفات:** أي تغيير في صيغة المشروع (`ProjectFile` في `src/store/project.ts`) يرفع `version` ويضيف ترحيلاً (migration)، بحيث تُفتح الملفات القديمة دون أخطاء. أضف اختباراً لملف قديم.
6. **التحقق:**
   ```bash
   npm run build && npm test && npm run e2e
   ```
   ثم تجربة يدوية في المتصفح: بالعربية والإنجليزية، وسطح المكتب والجوال، واللمس.
7. **الإنهاء:**
   - push، ثم PR إلى `main` يشرح ما أُضيف وكيف اختُبر، مع صور شاشة إن أمكن.
   - انتظر CI وأصلح أي فشل. **لا تدمج.**
   - حدّث جدول الحالة في آخر هذا الملف.

- [ ] **صفوف CAS مرقّمة**، والنتائج **رمزية ودقيقة** دائماً، مع زر ≈ للقيمة العددية. الإشارة إلى نتيجة صف سابق بـ `$1` و`$2`، ولآخر نتيجة بـ `$`.
- [ ] **الأوامر:**
  - `Simplify`، و`Expand`، و`Factor`.
  - `Solve` الرمزي، بمعاملات، مثل `Solve(a x^2 + b x + c = 0, x)` يعطي القانون العام.
  - `Solve` لأنظمة المعادلات.
  - `Substitute`، و`Derivative`، و`Integral` غير المحدد مثل `∫ x e^x dx = (x−1)e^x`.
  - `Limit`، و`Sum`، و`Numeric(expr, digits)`.

- [ ] **«إظهار في الرسم»** لكل صف (دائرة ملونة كما في GeoGebra): يعرض الرسم بجانب الصفوف في عرض مقسوم.

- [ ] ربط **الخطوات** (من جلسة أ2) بنتائج CAS حيث تتوفر.

**القبول:**
- `Integral(x e^x)` يعطي `(x - 1)e^x`.
- `Solve(x^2 - 2 = 0)` يعطي `x = ±√2`.
- `Limit(sin(x)/x, x, 0)` يعطي `1`.
- `Factor(x^4 - 1)` يعطي `(x−1)(x+1)(x²+1)`.
- اختبارات وحدة: ≥ 40 حالة رمزية، تُتحقق النتائج عددياً بنقاط عشوائية.
- حجم التحميل الأول للتطبيقات الأخرى لا يزيد (المحرك يُحمَّل بشكل كسول، ويُتحقق من ذلك في البناء).
